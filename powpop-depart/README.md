# powpop-depart

一个人出发，一群人抵达。

你一个人出发，在 PowPop 上留一条邀约：**从哪儿走、想去哪儿、哪天**。这条邀约钉在你的
出发点上，落到地图里，别人找得到。然后技能持续替你找可能同行的人，找到一个只问你一句
「**要不要搭一趟**」。

> **必须连接 PowPop MCP 才能工作**：`https://global.powpow.online/api/mcp`
> 没连上，发不了帖也搜不到人——技能会停下来直说，不会假装执行。

## 安装

```bash
npx skills add durenzidu/powpow-skills/powpop-depart
```

或者把 `powpop-depart/` 整个目录拷进你 agent 的 skills 目录。

## 玩法

1. **挂单**：问清起点、终点、时间、几人，写成一条固定格式的帖——
   `【一个人出发，一群人抵达】11月1日 周六 下午 · 从什刹海出发 · 想去武康路 · 2人 · 路线可以商量`
   草稿先给你看，你点头才发。帖子的地图坐标就是**起点**，所以「从附近出发的人」能被找到。
2. **找人**（三条线，两端都按距离判「相近」，不要求地名一致）：
   - **路 A** 出发帖池：`search_posts("一个人出发")`，同时看到出发地与目的地
   - **路 B** 起点侧：`find_nearby(place=起点, radius_meters=3000, types=['posts'])`
   - **路 C** 终点侧：`search_posts(我的目的地)`，靠 ILIKE 正文，不依赖出发帖
3. **提问**：按 R1 双近 → R2 终点近 → R3 起点近 → R4 提过 的顺序，**一次只提一个人**，
   带地点、对方原文一句、具体日期。你说不要，写进 `rejected`，永久不再提。
4. **守夜**：这一轮没人，主动提议挂每日定时任务替你继续扫，直到有人来或日期过去。

## 边界（写在正文里，不是口号）

- 只读别人的公开帖，**不关注、不私信、不评论、不加好友**
- 只把对方的帖子链接与主页链接交给你，**接触这一步永远由你自己做**
- 只改你自己的内容：发帖、状态帖都落在你本人账号下，每次先给草稿

## 冷启动的实话

PowPop 上「出发帖」现在是 0 条，近 30 天全站新增也就几十帖。所以第一次挂单**大概率
没人应**，会直接进守夜；能立刻给出的只有 R3 和 R4，量级各 1–10 个。这个玩法要靠每个
人先挂一条单才有池子——第一个人等得久，第十个人开始才有可能撞上。
